== Description ==

WP AJAX Search enhances the default WordPress search by including post content, tags, categories, authors, and custom fields. It also supports WooCommerce products, allowing users to search by product category, tags, and descriptions. The plugin provides a fast AJAX-powered live search experience.

== Features ==

* AJAX-powered live search results
* Search in post titles, content, excerpts, tags, categories, authors, and custom fields
* Supports custom post types, including WooCommerce products
* Configurable search fields and weighting
* Easy-to-use settings page

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/WP-AJAX-Search` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Go to Settings > Search Settings to configure the plugin.

== Frequently Asked Questions ==

= Does this plugin work with WooCommerce? =  
Yes, it supports searching WooCommerce products by title, description, category, and tags.

= Can I choose which post types and fields to search? =  
Yes, you can configure searchable post types and fields in the plugin settings.
